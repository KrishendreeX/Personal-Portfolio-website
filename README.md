##  Project Description & Purpose
This project is a multi-page personal portfolio website built from scratch to showcase who I am, my unique learning journey, technical skills, and recent coding projects. The purpose of this website is to establish my digital presence as an aspiring frontend developer, bridging my diverse background in customer service and cosmetology with my new trajectory in software development. 

The design reflects a modern, clean, and structured aesthetic using a personal color palette and smooth interactive elements that represent my professional growth and creativity.

---

##  Features
* **Multi-Page Navigation:** Seamless browsing across 6 distinct views: Home, About Me, Education, Skills, Projects, and Contact.
* **Interactive Education Timeline:** A dynamic, CSS-driven timeline tracking my career transition from childcare and cosmetology into corporate BPO roles and software development.
* **Responsive Project Showcase Grid:** A curated display of my latest development work featuring smooth hover effects and direct source-code links.
* **Functional Contact Form:** A beautifully styled user-feedback form integrated directly with Formspree for live message handling.
* **Social Integration:** Persistent navigation headers and footers carrying official links to my professional LinkedIn and GitHub accounts.

---

## Built With

### HTML Concepts Used
* **Semantic Architecture:** Built using clean layout boundaries including `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
* **Forms & Data Capture:** Implemented accessible `<form>` structures with specified text, email, telephone inputs, textareas, and explicit `<label>` attachments.
* **Media Handling:** Structured image elements carrying descriptive `alt` tags for search engine optimization and web accessibility.
* **Navigation & Linking:** Implemented clean anchor tag paths mapping local documents (`index.html`, `about.html`, etc.) alongside global target attributes.

### CSS Concepts Used
* **Layout Orchestration:** Handled using modern **Flexbox** alignments for the global navigation system and **CSS Grid** structures for the multi-card layouts.
* **Custom Typography:** Integrated Google Fonts functionality using the 'Poppins' font family.
* **Component Styling:** Advanced styling using the standard Box Model (padding, margins, borders) alongside modern transition animations on hover status.
* **Responsive Design:** Embedded media queries ensuring component fluidness on small screen environments.
